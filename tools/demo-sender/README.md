# 쿠키패트롤 USB 시연

Windows에서 연결된 안드로이드 기기에 시연용 메시지 알림을 보냅니다. 기기에는 **쿠키패트롤 시연** 알림이 도착하고, 쿠키패트롤이 평소와 같은 규칙으로 검사합니다. USB로 전달돼 SIM 카드와 문자 요금이 필요 없습니다.

1. 안드로이드 11 이상 기기를 USB로 연결하고 **USB 디버깅 허용**을 누릅니다. 기기의 쿠키패트롤에서 **문자·카톡 알림 감시**와 **위험 경고 팝업**을 켭니다.
2. 이 폴더의 `Start-CookiePatrol-Demo.cmd`를 엽니다.
3. 기기를 고르고 **기기 준비**를 누릅니다. 시연용 앱을 처음 설치할 때는 쿠키패트롤의 앱 설치 경고가 별도로 표시될 수 있습니다.
4. 기기 잠금을 풀어 두고 시연 예제를 골라 **기기에 보내기**를 누릅니다. **랜덤 예제**를 누르면 다른 예제 문구가 선택됩니다. 본문은 직접 수정할 수 있습니다.
5. PC 창의 **쿠키패트롤 검사 결과**에서 실제 점수와 경고 단계·건수를 확인합니다. 예제를 그대로 보내면 기대한 결과와도 비교합니다. 자동 확인은 휴대폰에 최신 시연용 쿠키패트롤 빌드가 설치되어 있을 때 지원됩니다. 휴대폰 팝업을 누르면 위험 신호를 볼 수 있습니다.

같은 내용을 연속으로 누르면 3초 동안 한 번만 전송합니다. 같은 예제를 다시 시연하려면 잠시 기다렸다가 보내세요.

| 시나리오 | 확인할 결과 |
| --- | --- |
| 정상 안내 | 0점, 위험 팝업 없음 |
| 결제 취소 사칭 | 3점, 2단계, 전화번호 근거 |
| 변경 계좌로 송금 유도 | 3점, 2단계, 계좌번호 근거 |
| 복합 위험 · 기기 검사 | 7점, 2단계, 링크·전화번호·계좌번호 근거 |
| 피싱 링크 · Google 위험 목록 테스트 | 1점, Google 목록 일치 시 3단계 |
| 복합 위험 · Google 위험 목록 테스트 | 7점, Google 목록 일치 시 같은 경고가 3단계로 갱신 |

Google 시나리오에는 쿠키패트롤의 **자동 링크 추가 검사**를 켜고 전체 메시지의 링크 검사에 동의해야 합니다. 백엔드도 실행되어 있어야 합니다. 예제의 번호는 합성 값이며 3단계 확인에는 Google의 공식 테스트 주소를 사용합니다.

PC의 8000번 포트에서 백엔드를 실행하는 USB 시연은 저장소 루트에서 아래 명령으로 디버그 앱을 설치합니다. 이 빌드는 휴대폰의 18000번 포트를 사용하며, 시연 도구의 **기기 준비**가 해당 포트를 PC의 8000번으로 연결합니다.

```powershell
.\frontend\gradlew.bat -p frontend "-PcookiePatrolDebugApiBaseUrl=http://127.0.0.1:18000" :app:installDebug
```

Windows에는 Android SDK Platform-Tools가 설치되어 있어야 합니다.

이 저장소에서 시연용 APK를 직접 빌드할 때는 Android SDK Build-Tools와 JDK가 필요합니다.
