## 팀원이 제공한 협업 경험

2026-11-16 대화에서 제공받은 내용: 백엔드 구현이 잘 풀리지 않아 멘토링 날 외에도 별도의 미팅을 잡고 팀원들과 코딩을 이어갔다. 이 과정에서 협업·의사소통과 팀원 간 친밀감이 높아졌다.

이 내용은 **팀원 제공 경험**이며 Git만으로 재구성한 이야기가 아니다. 아래를 채우기 전에는 특정 오류나 해결책을 이 모임의 성과로 단정하지 않는다.

| 확인할 항목 | 팀원 입력 |
|---|---|
| 미팅 날짜·장소·참여자 | 팀원 확인 필요 |
| 막혔던 기능과 실제 오류 메시지(비밀값 제거) | 팀원 확인 필요 |
| 외부 API 연동 담당 / 검사 로직 담당 | 팀원 확인 필요 |
| 테스트 작성 / 앱 통합 / 리뷰 담당 | 팀원 확인 필요 |
| 서로 달랐던 의견 | 팀원 확인 필요 |
| 함께 선택한 해결 방법·이유 | 팀원 확인 필요 |
| 해결을 확인한 테스트·커밋·PR | 팀원 확인 필요 |
| 다음 작업에 반영한 협업 습관 | 팀원 확인 필요 |

| 2026-11 남은 기간 | 제안 일정 | 다른 기기 2~3대 확보, 문자/카톡 60개 관찰, 글자 확대·절전·재연결 시험 | 각 기기의 실험 JSON·실기기 표·2~3분 영상. 담당자·날짜 팀원 입력 |
| 2026-12 또는 본선 전 | 제안 일정 | 독립 라벨 검토, 실제 API 비교(키 설정 후), 발견 오류 수정·재시험 | 실제/모의 결과 구분, 새 평가용 보존. 본선 날짜·일정 팀원 확인 필요 |

예정 작업은 완료 이력으로 발표하지 않는다. 멘토링 외 미팅의 실제 날짜는 아직 알 수 없어 월별 완료 목록에 임의로 넣지 않았다.
