# 실기기 검증과 시연

현재 상태: **실기기 미검증 / 이번 작업의 에뮬레이터 시험 미실행**. `adb devices -l`에서 연결된 기기가 없었다. 과거 에뮬레이터 시연 기록과 이번 자동 테스트를 실기기 성공으로 표시하지 않는다. 실제 기기 조작·촬영은 팀 담당자가 수행한다.

## 설치와 준비

저장소 루트에서 `scripts/verify.ps1`을 실행해 빌드한다. APK는 `frontend/app/build/outputs/apk/debug/app-debug.apk`다. 실제 폰의 외부 검사 서버는 HTTPS여야 한다. 에뮬레이터 전용 `http://10.0.2.2:8000`은 실제 폰에서 PC를 가리키지 않는다.

```powershell
Push-Location frontend
./gradlew.bat assembleDebug -PcookiePatrolApiBaseUrl=https://팀이-운영하는-백엔드-주소
Pop-Location
& "$env:ANDROID_HOME/platform-tools/adb.exe" devices -l
# 연결된 특정 시험 폰을 선택해 담당자가 설치한다.
& "$env:ANDROID_HOME/platform-tools/adb.exe" -s 기기ID install -r frontend/app/build/outputs/apk/debug/app-debug.apk
```

기기 ID는 로컬 설치 명령에만 사용하고 발표 자료·공유 로그에 남기지 않는다. 앱 홈에서 필요한 기능을 눌러 목적·읽는 정보·전송 범위·설정/해제 방법을 읽고 켠다. 실험하지 않는 화면 감시는 끈다. 알림 접근 권한이 켜졌다는 표시와 실제 서비스 연결 표시를 각각 확인한다. APK·원격제어 앱은 시험 전용 기기에만 직접 판단해 설치하며 경고 실험을 위해 악성 앱을 설치하지 않는다.

## 60개 실제 수신 실험

디버그 앱 홈의 **실험 기록**을 연다. 기본 제공 평가용 60개를 사용한다. 이는 앱 안에서 문장을 평가하는 수치와 실제 수신 관찰을 구분해서 보여준다.

1. 문자/SMS 또는 KAKAO와 ONLINE/OFFLINE을 선택한다. 이미 결과를 기록했다면 JSON 내보내기 후 새 세션으로 바꾼다. 인터넷이 실제로 꺼졌는지는 담당자가 확인한다.
2. 문장 복사 후 다른 기기에서 해당 문자/메신저로 보낸다. 이 화면은 알림이나 위험 경고를 생성하지 않는다.
3. 수신과 검사 시간을 확인한다. 오프라인은 최소 5초, 온라인은 다른 검사 대기가 없는 상태에서 최소 30초 관찰한다. 다수 URL/대기 작업이 있으면 완료 여부가 불분명하므로 판단 불가로 기록한다.
4. ‘수신 확인·경고 있음/없음’, ‘미수신’, ‘판단 불가’ 중 실제 관찰을 선택한다. ‘추가 검사를 마치지 못했어요’ 같은 실패 안내는 위험 탐지 성공이 아니라 **판단 불가**로 기록한다. 정답 라벨만 보고 예상 결과를 기록하지 않는다.
5. 같은 ID를 고치면 해당 세션의 마지막 관찰로 교정된다. 반복 실험은 새 세션으로 만든다. 사전에 JSON을 내보내지 않은 기록은 새 세션에서 지워진다.
6. JSON을 내보내고 위 기본 기록표와 함께 보관한다. JSON에는 기종·OS·앱 버전·문자 앱 패키지/버전(확인 가능한 경우)·권한·동의 상태·사례 ID·수동 결과·시각·지표가 포함된다. 다른 앱은 패키지/버전을 기본 기록표에 직접 적는다.

첫 관찰 때 시험 환경과 데이터·규칙 해시를 고정한다. 앱/기기/데이터/규칙/서버 환경 등이 달라진 기존 세션은 새 결과를 추가하거나 현재 지표에 합산할 수 없다. schema_version 2 내보내기에서 `incompatible_session_unaggregated`와 지표 제외를 확인하고 기존 기록을 보관한 뒤 새 세션을 시작한다. 서명이 없는 예전 기록도 합산하지 않는다. 자동 알림 수신 시험이 아니라 담당자가 관찰하는 화면이다. 기본 합성 자료 자체의 의미 유사성 때문에 독립적인 실사용 정확도 증명으로도 사용하지 않는다.

원문·전화번호·실제 인증번호·기기 고유 식별값은 저장하지 않는다. 기종·시각도 개인정보와 결합될 수 있으므로 내보낸 파일 공개 범위는 팀에서 정한다. 수동 기록은 서명된 자동 수신 증명이 아니며, 실제 화면 영상이나 담당자 관찰표로 보완한다. 실행 전 정답을 알고 있으므로 관찰자 편향도 남는다.
